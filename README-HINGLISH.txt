BMW FUTURE — START HERE

1. Extract the ZIP.
2. Keep index.html, style.css, and script.js together in the same folder.
3. Open index.html in Chrome. Internet connection is needed for remote car photos and Google Fonts.
4. Recommended: open the folder in VS Code and run using Live Server.

GITHUB PAR UPLOAD KARNE KE STEPS
A) github.com par login karo.
B) New repository banao, naam: BMW-FUTURE (Public choose kar sakte ho).
C) Repository create karte waqt README, .gitignore, aur license add mat karna (empty repo rakho).
D) Add file > Upload files par click karo.
E) Is folder ke andar ki files/folders select karke drag-drop karo: index.html, style.css, script.js, README-HINGLISH.txt.
F) Commit changes par click karo.

LIVE WEBSITE (GitHub Pages)
1. Repo > Settings > Pages kholo.
2. Build and deployment mein Deploy from a branch select karo.
3. Branch: main, folder: /(root), phir Save.
4. Kuch minutes baad Pages section mein jo URL mile usko kholo.

IMAGE NOTE: Car photos load from Unsplash over the internet; they are not stored inside this ZIP. If a photo URL fails, the page now shows a dark cyan fallback instead of a broken-image icon. For actual photos, stay connected to the internet.

NOTE: BMW FUTURE is an unofficial design concept and is not affiliated with BMW AG.
